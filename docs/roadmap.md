# Roadmap

## MVP Phase Scope
- Full ECO dataset A00–E99 (~3,500+ openings & variations)
- Interactive Board with drag-and-drop & move controls
- Real-time opening & transposition identification
- Dynamic variation panel and interactive variation tree
- Global search by name, ECO code, move sequence, or position
- Responsive shell for desktop, tablet, and mobile
- FEN and PGN import/export

## Post-MVP Future Possibilities
- Opening Repertoire builder (saving custom line trees)
- Stockfish WASM evaluation integration
- Spaced repetition training for opening lines
- Opening comparison view
